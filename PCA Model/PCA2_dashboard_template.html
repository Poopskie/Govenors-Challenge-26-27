Model specification, data sources, and limitations

Specification. Next-quarter CPI-trim = intercept + β × PC1 + γ × current CPI-trim. PCA uses six indicators: IPPI, RMPI, crude energy, food CPI, gasoline CPI, and hourly wages, each converted to year-on-year growth.

Estimation. PCA scaling and loadings use complete 2000–2019 quarters. Regression uses all available complete pairs; historical fitted values are not real-time forecasts. The display range changes charts only, not the model.

Limits. Costs and energy dominate this index. Expectations and diesel are not included yet. Data are revised snapshots, not real-time vintages. The 80% prediction interval uses ordinary linear-model assumptions; no robust or forecast-validation adjustment has been added.
